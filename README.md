## How it works

1. Fill the CSV with reviewer comments and your own responses.
2. Enter the manuscript title, journal, authors and opening text.
3. Double-click the Windows launcher to generate both DOCX and HTML.
4. Continue editing the DOCX in Word or a compatible editor, or print the HTML to PDF in a browser. Save direct Word edits under a new filename because rerunning the generator replaces its output files.

The package includes the local generator, launcher, blank CSV, metadata template, fictional examples, ten editable response structures and a quick-start guide. Rows are exported in spreadsheet order, including unfinished items and author-entered status labels.

**Requirements:** Windows PowerShell 5.1 and an editor that saves comma-delimited UTF-8 CSV. Word is not required to generate files; a compatible document editor is needed to edit DOCX.

**Scope:** Plain-text formatting only. It does not import manuscript figures, equations or tracked changes, write scientific responses, validate citations or guarantee acceptance. Version 0.2 is a prototype: a fictional example has been generated, but comprehensive compatibility testing and customer trials have not been completed.
