## How it works

1. Fill the CSV with your reviewer comments and your own responses.
2. Enter the manuscript title, journal and authors.
3. Run the local launcher to create the HTML response letter.
4. Open it in a browser and print to PDF, or open the HTML in desktop Word for further editing.

The generator uses no AI API, login, remote storage or network connection. It formats the text you provide. It does not invent scientific results, validate citations, edit your manuscript or guarantee acceptance. It does not export a native DOCX file.

**Requirements:** Windows with Windows PowerShell 5.1 and a browser. An editor that saves comma-delimited UTF-8 CSV is needed; Excel, LibreOffice or a text editor can be used. Managed computers may restrict local scripts.

**Release status:** Version 0.1 prototype. No comprehensive compatibility testing or customer trial has been completed. Review the samples and ask about suitability before paying.
